# Flower · Ion Rose

为七夕制作的单页 Canvas 动画：随着页面滚动，一朵由粒子组成的玫瑰逐渐绽放。

## 交互与实现

- 滚动驱动的花瓣绽放与分段文案
- Canvas 2D 粒子绘制、星空与流星效果
- 移动端布局与“再看一次”交互
- 原生 HTML、CSS、JavaScript，无构建依赖

## 本地预览

直接用浏览器打开 `index.html`，或在仓库目录启动静态服务：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 项目定位

一个独立的个人创意作品，保留现有页面内容。入口文件：[`index.html`](index.html)。
